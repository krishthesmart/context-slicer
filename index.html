Setup in 30 Seconds

Choose your integration: MCP, Proxy, or SDK.

Add ContextSlicer to any MCP client (stdio JSON-RPC 2.0) to persist and recall save_slice, get_slice, and list_slices: 

{
  "mcpServers": {
    "context-slicer": {
      "command": "node",
      "args": ["src/mcp.js"],
      "env": {
        "CONTEXT_SLICER_DB": ".context-slicer-slices.json"
      }
    }
  }
}

Run locally with Node.js or deploy worker.js to Cloudflare Workers (free tier, no credit card): 

# Start local OpenAI-compatible streaming proxy
npm start

# Test with curl (returns X-Context-Saved header)
curl -N http://localhost:8787/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "X-Session-Id: sprint-42" \
  -d '{
    "model": "gpt-4o-mini",
    "stream": true,
    "messages": [{"role": "user", "content": "build it"}]
  }'

Embed the zero-dependency CommonJS SDK directly in your Node.js app: 

const { ContextSlicer } = require('./src/core');

const slicer = new ContextSlicer({ windowSize: 6 });
slicer.addTurn('user', 'Let us build a URL shortener Build fast URL shortener');
slicer.addTurn('assistant', 'Agreed. Use SQLite + Node http');

// Chat mode: [WORKING_MEMORY] + recalled + last N turns + userMsg
const chatPayload = slicer.buildMessages('What database did we pick?');

// Execute mode: drops brainstorm window, sends ONLY [WORKING_MEMORY] + userMsg
const buildPayload = slicer.buildMessages('build it');
